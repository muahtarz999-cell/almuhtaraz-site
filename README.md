# 🏢 موقع شركة المحترز للمقاولات العامة

موقع تعريفي أنيق ومتحرك (صفحة واحدة) يعرض قطاعات الشركة ومشاريعها وحلولها الرقمية،
بتجربة بصرية راقية وخطوط عربية أصيلة.

## ✨ المزايا
- واجهة سينمائية تفاعلية مع شعار متوهج وسكاي لاين يُبنى تلقائياً.
- خلفية جسيمات ذهبية تفاعلية (Three.js) تستجيب لمؤشر الفأرة.
- تمرير حريري فاخر (Lenis) وحركات ظهور عند التمرير (GSAP + ScrollTrigger + AOS).
- بطاقات بلمسة ثلاثية الأبعاد وتوهج زجاجي (Vanilla Tilt).
- بوابات تفاصيل غامرة: تفاصيل المشاريع ومعرض الحلول الرقمية والأنظمة.
- صور ناطقة عبر توليد الكلام (Web Speech Synthesis) ومحاكي هاتف حي.
- لوحة إدارة مدمجة لتعديل المشاريع والصور والخطوط (تعمل عند النشر على المنصات الداعمة).

## 🚀 المعاينة والتشغيل
- **محلياً:** افتح الملف `نسخة للنشر/index.html` مباشرة في المتصفح، أو شغّله عبر **Live Server**.
- **النشر:** يستخدم Vercel مجلد `نسخة للنشر/` كمصدر للنشر وفق إعداد `vercel.json`.

> ملاحظة: لعرض الصور وملف البيانات بشكل صحيح عند التشغيل المحلي، يُفضّل استخدام خادم محلي
> (Live Server) بدلاً من فتح الملف مباشرة، لأن المتصفح قد يمنع قراءة `data/site.json` عبر بروتوكول `file://`.

## 📁 هيكلية المشروع
```
نسخة للنشر/              مجلد الموقع الجاهز للنشر
├── index.html          صفحة الموقع كاملة (HTML + CSS + JS)
├── data/site.json      بيانات المشاريع والصور والخطوط
├── img/                صور الشركة والمشاريع
├── robots.txt          تعليمات الزحف ورابط خريطة الموقع
└── sitemap.xml         خريطة الموقع لمحركات البحث
```

تتضمن الصفحة بيانات SEO وOpen Graph وبيانات الشركة المنظمة (JSON-LD). تُحدّث معلوماتها في `نسخة للنشر/index.html`، مع إبقاء النطاق الأساسي متوافقًا مع إعدادات Vercel.

## 📝 التعديل
- **بدون برمجة:** افتح `data/site.json` وعدّل نصوص المشاريع، أو استبدل الصور في مجلد `img/` بنفس الأسماء.
- **عبر اللوحة:** عند نشر الموقع على منصة تدعم التحرير، يظهر زر «⚙ إدارة الموقع» لإدارة المشاريع والصور والخطوط مباشرة.
